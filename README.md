# my-portfolio

Учебный статический сайт-портфолио, опубликованный с помощью GitHub Pages.

## Содержимое

- `index.html` — главная страница с разделами «О себе», «Навыки» и «Проекты»;
- `styles.css` — оформление страницы;
- `.github/workflows/ci.yml` — workflow GitHub Actions с приветствием;
- `.github/ISSUE_TEMPLATE/` — шаблоны задач;
- `SECURITY.md` — политика безопасности.

## Публикация

Сайт публикуется из ветки `main` через GitHub Pages:

<https://akostt.github.io/my-portfolio/>

## Локальный просмотр

```bash
python3 -m http.server 8000
```

После запуска страница доступна по адресу <http://localhost:8000>.
