# Политика безопасности

## Сообщение об уязвимости

Пожалуйста, не создавайте публичный issue. Напишите на
[security@example.com](mailto:security@example.com) и опишите проблему,
шаги воспроизведения и возможные последствия.

Мы постараемся ответить в течение трёх рабочих дней.

## Поддерживаемые версии

| Версия | Поддержка |
| ------ | --------- |
| 1.x    | Да        |

## Рекомендации

- не публикуйте токены, пароли и ключи в репозитории;
- используйте секреты GitHub Actions для чувствительных значений;
- включайте двухфакторную аутентификацию в аккаунте GitHub.
